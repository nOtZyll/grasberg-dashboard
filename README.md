# Grasberg: operasi & jejak tailing

Situs statis hasil build. Kode sumber dan pipeline analisisnya ada di repo
riset yang terpisah dan belum dipublikasikan.

Seluruh analisis dibangun dari sumber publik: filing SEC Freeport-McMoRan,
citra satelit terbuka (Landsat dan Copernicus), data curah hujan publik
(CHIRPS), dan kapasitas smelter yang sudah dipublikasikan. Tidak ada data
internal PT Freeport Indonesia yang dipakai.

Analisis independen. Bukan produk PT Freeport Indonesia.
